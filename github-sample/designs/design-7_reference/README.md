# Design 7: Premium SaaS Split-Bento & Feature Stack Grid

**Directory:** `designs/design-7_reference/`

## Visual Archetype & DNA
- **Aesthetic:** Modern, crisp, clean Light-Mode Tech SaaS (Google / Canva / Apple design language).
- **Background & Ambiance:** Pristine soft off-white canvas (`#F8FAFC` to `#F1F5F9`) with subtle, diffused ambient pastel airbrush blooms in the corners (mint green, sky blue, gentle lavender blur).
- **Layout Architecture (Split Bento Grid):**
  1. **Top Header:** Clean brand logo & title (e.g. `Canva Pro`) in bold modern typography with a Bengali sub-headline (`স্মার্ট ডিজাইনের আল্টিমেট সলিউশন`), accompanied by a floating 3D glowing asset/star on the opposite corner.
  2. **Left Column (Hero Value Card):**
     - Large rounded rectangular squircle container featuring a rich, saturated brand gradient (e.g., Canva cyan-to-purple gradient `#00C4CC` -> `#7D2AE8`).
     - Contains an official 3D product token (e.g., Canva 3D Logo or Cloud/Storage symbol) + massive typography emphasizing the flagship perk (e.g., `100M+` or `UNLIMITED` or `1TB Storage`).
     - **Unique Price Callout (High-Contrast Ticket Pill):**
       - The price is **NEVER** displayed as ordinary plain text.
       - Framed inside a stark white rounded pill badge / floating ticket container with soft directional drop shadow.
       - Inside typography: High-contrast bold brand color (e.g. deep royal purple `#7D2AE8` or electric blue `#0062FF`) reading `মাত্র ৫০ টাকা` or `মাত্র ৯৯ টাকা`, making the price immediately pop out with 10x visual stopping power compared to all other body text.
  3. **Right Column (Vertical Stacked Feature Micro-Cards):**
     - 5 to 6 sleek horizontal white cards with soft drop shadows and rounded corners.
     - Each card features:
       - Vibrant colored 3D/vector app or tool icon (Magic Studio, BG Remover, 100M+ Stock Media, Pro Fonts/Brand Kit, 1TB Cloud, Personal Email Activation).
       - English Feature Headline (e.g., `Magic Studio AI`, `Background Remover`).
       - Bengali benefit description (e.g., `১ ক্লিকে ব্যাকগ্রাউন্ড রিমুভ`, `প্রফেশনাল AI টুলস`).
       - Optional micro-pill badge (e.g., `আনলিমিটেড`, `প্রিমিয়াম`).
  4. **Bottom Trust & Security Bar:**
     - Horizontal full-width white rounded card featuring 4 security trust badges:
       - Shield Checkmark: `100% Safe / নিরাপদ ও গ্যারান্টিড`
       - Lightning Bolt: `Instant Activation / ৫ মিনিটে এক্টিভেশন`
       - Person/Email Icon: `নিজের মেইলে / পার্সোনাল এক্টিভেশন`
       - Handshake/Shield: `আগে কাজ, পরে টাকা / বিশ্বস্ত সার্ভিস`
  5. **Call-to-Action (CTA):**
     - Bottom centered bold rounded pill button with Messenger icon: `অর্ডার করতে মেসেজ করুন`.

## Context Triggers (When to Use Style 7)
- Multi-feature breakdowns (explaining everything included in the subscription).
- High-trust comparison offers for customers who want to know all technical perks.
- Clear price-point sales promotions (25 TK, 50 TK, 99 TK) where transparent pricing and comprehensive features seal the deal.
- Bangladeshi Facebook audience looking for clear trust guarantees (`নিজের মেইল`, `আগে কাজ পরে টাকা`, `ইনস্ট্যান্ট এক্টিভেশন`).
