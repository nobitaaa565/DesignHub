# Design 10: 3D Hardcover Book, Isometric Metaphor & Cyber Relational Schema

**Directory:** `designs/design-10_reference/`

## Visual Archetype & DNA
- **Aesthetic:** Deep cyber technical education, programming masterclass, and designer course launch.
- **Background & Ambiance:** Obsidian navy to charcoal space with faint server silhouettes and glowing cyan floor grid lines.
- **Layout Architecture (Geometry I):**
  1. **Top Headline:** High-contrast two-tone headline: `ডিজাইন শেখো` in crisp white, `ঘর গোছানোর মতো` in glowing cyan (`#22D3EE`), with subtitle line `৪৮টি রিসোর্স • একদম শুরু থেকে`.
  2. **Center-Right Hero Book:** Upright 3D hardcover book mockup with tangible embossed spine, textured dust jacket, and realistic contact shadow. Book cover artwork features an intricate miniature 3D isometric designer's creative workshop with warm internal lighting.
  3. **Center-Left Schema Grid:** Floating translucent holographic cards (`Templates`, `Brand Kit`, `Magic AI`) with glowing neon cyan relational connection paths.
  4. **Lower-Left Price Arrow:** Dynamic cyan arrow pointer pill badge highlighting the price `[ মাত্র ২৫ টাকা ]` or `[ মাত্র ৳১১১ ]`.
  5. **Bottom CTA:** Rounded dark button with neon cyan perimeter glow and cart icon `[ 🛒 এখনই এক্টিভ করো ]`.
