# Design 10: 3D Hardcover Book, Isometric Metaphor & Cyber Relational Schema

## Benchmark Reference
- **File:** `reference.jpg` / `tech_book_database_cyber_promo.jpg`
- **Category:** Tech Books, Programming Guides, Masterclasses, Developer & Designer Courses
- **Format:** Square (1:1, 1080x1080) & Facebook Portrait (4:5, 1080x1350)

## Visual Architecture
1. **Headline Zone (Top-Center):**
   - High-contrast, bold Bengali metaphor headline:
     `ডাটাবেজ শেখো` in crisp off-white,
     `ঘর গোছানোর মতো` in luminous cyan/teal (`#22D3EE`).
   - Clean horizontal subtitle line with book/course specs (`৪৮টি অধ্যায়, ২৬৬ পৃষ্ঠা — একদম শুরু থেকে`).
2. **Hero Book Centerpiece (Right-Center):**
   - Premium upright 3D hardcover book mockup with tangible spine, beveled paper block, and dynamic contact shadow.
   - Cover artwork: intricate isometric physical metaphor (e.g. vintage library archive with character organizing server drawers representing databases).
3. **Relational Schema Grid (Left Side):**
   - Floating translucent database table cards (`users`, `orders`, `order_items`) with columns and `PK` / `FK` pills, linked by glowing neon cyan relational connector paths.
4. **Dynamic Price Arrow Badge (Lower-Left):**
   - Sleek cyan/teal arrow pointer pill badge highlighting the price: `[ মাত্র ৳১১১ ]` or `[ মাত্র ২৫ টাকা ]`.
5. **Glowing CTA Button (Bottom-Center):**
   - Dark button with neon cyan perimeter glow and cart icon: `[ 🛒 এখনই অর্ডার করো ]`.
